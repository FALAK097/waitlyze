Waitlyze can send signup-milestone messages to one Slack channel and one Discord channel per waitlist. These are best-effort notifications, not a general event stream.

The channel handlers currently have no dedicated settings form in the app. Managing a channel uses a session-protected waitlist endpoint and requires waitlist-management access; signup API keys are not accepted.

## Shared behavior

- Messages are sent when a published waitlist reaches **1, 10, 100, or 1,000 signups**.
- Only plain-text milestone summaries are sent; no individual signup details or referral events are included.
- A failing channel is marked as needing attention and skipped. Signup intake, owner email, and webhooks continue independently.
- Use [Webhooks](/docs/webhooks) for signed event payloads, retries, and delivery recovery.
