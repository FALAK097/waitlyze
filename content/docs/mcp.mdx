Waitlyze provides a first-class Model Context Protocol (MCP) server. You can manage your waitlist lifecycle, create campaigns, inspect signups, evaluate K-factor viral analytics, dispatch broadcasts, and inspect connections directly from inside ChatGPT, Claude Code, Cursor, Codex, VS Code, Gemini, or OpenCode without opening the web dashboard.

---

## Quick start

The MCP server runs at:

```
https://waitlyze.com/mcp
```

### Authentication methods

You can authenticate AI agents in two ways:

- **Scoped API key**: generate an API key in **Settings → API keys** (prefixed with `wl2_`). Pass it as an HTTP Bearer header (`Authorization: Bearer wl2_YOUR_KEY`) or in `x-waitlyze-api-key`.
- **OAuth 2.0**: point your client to `https://waitlyze.com/mcp`. The agent discovers the authorization server and initiates RFC 9728 authentication.

## Client setup

<Steps>
<Step>
### Set up Claude Code
Add Waitlyze to Claude Code with one command:

```bash
claude mcp add --transport http waitlyze https://waitlyze.com/mcp --header "Authorization: Bearer wl2_YOUR_API_KEY"
```

If connecting via OAuth:
```bash
claude mcp add --transport http waitlyze https://waitlyze.com/mcp
```
</Step>

<Step>
### Set up Cursor
In your project root, create or edit `.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "waitlyze": {
      "url": "https://waitlyze.com/mcp",
      "headers": {
        "Authorization": "Bearer wl2_YOUR_API_KEY"
      }
    }
  }
}
```
</Step>

<Step>
### Set up Codex
Add Waitlyze to your agent configuration:

```json
{
  "mcpServers": {
    "waitlyze": {
      "url": "https://waitlyze.com/mcp",
      "headers": {
        "Authorization": "Bearer wl2_YOUR_API_KEY"
      }
    }
  }
}
```
</Step>

<Step>
### Set up VS Code
In your VS Code settings or MCP configuration:

```json
{
  "mcp.servers": {
    "waitlyze": {
      "type": "http",
      "url": "https://waitlyze.com/mcp",
      "headers": {
        "Authorization": "Bearer wl2_YOUR_API_KEY"
      }
    }
  }
}
```
</Step>

<Step>
### Set up OpenCode
In your `opencode.json` configuration:

```json
{
  "mcpServers": {
    "waitlyze": {
      "url": "https://waitlyze.com/mcp",
      "headers": {
        "Authorization": "Bearer wl2_YOUR_API_KEY"
      }
    }
  }
}
```
</Step>

<Step>
### Set up Gemini
Configure the server endpoint in your agent tool manifests:

```json
{
  "name": "waitlyze",
  "url": "https://waitlyze.com/mcp",
  "transport": "streamable_http"
}
```
</Step>
</Steps>
